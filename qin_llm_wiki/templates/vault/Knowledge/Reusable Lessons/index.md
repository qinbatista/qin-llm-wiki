# Reusable Lessons

This taxonomy holds current, cross-project patterns distilled from verified outcomes. Current source, fresh runtime evidence, and explicit user intent always outrank an older lesson.

Read project → task → underlying logic. Use explicit `applies-logic` relations to shared `logic.*` principle entries and original project cases. Compare applicability, implementation differences and proof limits before reuse. Keyword/category matches only propose candidates; project counts alone do not create a shared rule. Do not preload whole categories or unrelated project facts at task entry.
